Operations

Terminal and Database Suite

Deploy work is rarely isolated. You usually need shell access, live query checks, and fast diagnostics. This suite keeps those tasks inside one UI flow.

Terminal Workspace

Session Types

  • Local terminal sessions for project scripts.
  • SSH terminal sessions for server operations.
  • Multiple terminal panes and detached windows.

Execution Helpers

  • Preset command insertion through quick selectors.
  • Optional broadcast input across open terminals.
  • Cleaner ANSI rendering and control-key handling.

Database Workspace

Interactive Tools

  • Schema and table browser with quick refresh.
  • SQL editor with autocomplete-ready workflow.
  • Saved profile model for local and remote DB endpoints.

Operational Jobs

  • Import workflows with controlled target selection.
  • Processlist and health-check style diagnostics.
  • Compatibility with backup validation routines.

Typical Incident Flow

  1. Open Terminal tab to verify runtime services and logs.
  2. Use Database tab to inspect impacted data quickly.
  3. Patch via Deploy or Direct Upload with minimal delay.
  4. Run targeted backup validation for confidence.
  5. Record actions in History and continue with release sync.
Best practice: keep one detached terminal and one DB panel open during deploy windows for rapid feedback.
