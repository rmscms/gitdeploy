Backup

Backup Scheduler and Validation Automation

Backup in GitDeploy Pro is not just file creation. It includes scheduling, execution tracking, restore validation, and operator-level visibility for each stage.

Scheduler Capabilities

Task Lifecycle

  • Create backup plans with cadence and retention rules.
  • Run on demand or via automated schedule triggers.
  • Auto-start support and missed-run recovery logic.

Operational Visibility

  • Active tasks modal with status and control actions.
  • Progress and logs shown during run-time execution.
  • History updates are written per project for traceability.

Validation Stages

Restore validation can be staged so teams can quickly identify exactly where a backup fails.

  • connect: validate DB connectivity and runtime prerequisites.
  • import: replay dump into validation target and inspect SQL behavior.
  • cleanup: verify post-validation cleanup and environment stability.

Warnings and failures can be replayed manually from history actions, making incident investigation faster.

Integrity Sampling Workflow

Sampling Modal

  • Shows largest tables from latest validation sample.
  • Lets operators inspect snapshot rows quickly.
  • Useful for confidence checks before promotions.

History Integration

  • Backups can be re-validated from the history grid.
  • Uses schedule-linked validation preferences.
  • Stores updated outcomes for audit continuity.

Backup Packaging Formats

  • Raw SQL output for direct data workflows.
  • Archive outputs (ZIP / TAR.GZ) for transport and storage.
  • Health and validation metadata aligned with run history.
Operator guideline: treat each backup as a testable artifact, not just a generated file.
