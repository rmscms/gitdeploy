GitDeploy Pro — Deploy

Features

Everything that used to live in five tools.

Ship, inspect, recover and talk to your stack without leaving the desk.

Git + Deploy

Compare branches, review changed files, commit, push and deploy in one flow — with rollback one click away.

FTP / SFTP workspace

Browse, edit, sync and recover remote files with path mapping and conflict-aware transfers.

Direct Upload

Pick files or folders and push them straight to the server with parallel workers and crash recovery.

Terminal

Local and SSH sessions with saved command presets and suggestions, right next to your deploy.

Database Studio

Connect to MySQL / MariaDB, browse tables, run queries and import dumps without another client.

Scheduled backups

A guided 6-step wizard, optional OpenVPN per plan, localhost restore validation and a live run log.

Screens

Designed to be read at a glance.

A dark, calm interface with real icons, clear status colors and consistent controls. Click any screenshot to enlarge.

Deploy. Branch chips with ahead/behind counters, a changed-files list with status badges, and the remote file tree beside it.

Direct Upload. Parallel workers, live progress and crash recovery for large uploads.

Backups. A step-by-step wizard, a timeline of next runs and a live log while a backup is running.

Database Studio. Query editor, results grid with colored status values, and process list.

Dashboard. Project status, quick actions and recent backup activity in one place.

GitHub. Clone, pull, push and tag from a single page.

History. Search commits by file path and roll back with a preview.

Settings. Searchable sections, an unsaved-changes bar and a one-click Save.

Workflow

From commit to live path.

A straight operator loop — no dashboard clutter, no ceremony.

1Connect

Project path, server profile and optional VPN keep-alive.

2Compare

See local vs remote and stage exactly what changed.

3Ship

Deploy the selected files, watch progress, verify on the remote tree.

4Stay up

Scheduled backups, agent chat and auto-reconnect when the network blinks.

AI agents

Run your project from Telegram.

Send a message from your phone and an AI coding agent works inside your project folder — with a per-project queue, Stop button, model picker and session resume.

  • Choose Cursor or Claude Code as the engine, switch any time with /engine
  • Login & test dialogs inside Settings, no terminal juggling
  • Terminal presets and SSH sessions available from the chat
